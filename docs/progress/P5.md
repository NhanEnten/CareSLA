# Tiến độ P5 - Gateway, Dashboard, Tổng hợp báo cáo

## Đã xong
- Tạo script `tools/make_test_vector.py` sinh `docs/test_vectors.json` khớp hoàn toàn byte-by-byte với contract (Giai đoạn 0).
- Chạy qua các bài test của contract xác nhận test vector chuẩn (đang hoàn tất).
- Tạo script `tools/gen_device_key.py` sinh khóa thiết bị, in ra định dạng dễ copy.
- Cài đặt cấu trúc, `backend/requirements.txt` và `pip install` thành công.
- Tạo file `.env.example` với đầy đủ các cấu hình môi trường cần thiết.
- Khởi tạo script cơ bản cho `backend/gateway.py` (Giai đoạn 1): Đã thiết lập MQTT subscriber, đọc, kiểm tra chữ ký off-chain, lưu SQLite và fallback gửi Telegram.

## Đang dở
- Tích hợp test end-to-end với MQTT Mosquitto trên máy thật (Giai đoạn 1).

## Đã xong mới nhất (Giai đoạn 2 & 3)
- **Gateway Blockchain (Giai đoạn 2)**: Hàng đợi Blockchain gửi `reportFall`/`confirmArrival` tuần tự, đọc ABI, và quét log `Escalated`.
- **Dashboard Web3 (Giai đoạn 2)**: Giao diện hoàn chỉnh kết nối MetaMask, lấy danh sách sự cố và hiển thị đếm ngược SLA.
- **Metrics và AI Fallback (Giai đoạn 3)**: Đã thêm tính năng sinh file `metrics.json` định kỳ từ SQLite để phục vụ biểu đồ trên Dashboard, tích hợp sẵn placeholder cho AI gateway.
- **Tài liệu bảo vệ (Giai đoạn 3)**: Đã viết xong `tong_quan_he_thong.md` (tài liệu chung cả nhóm) và `P5_on_phan_bien.md`.

## Lỗi tồn tại
- Chưa có lỗi, code đã hoàn tất đến mốc ĐÓNG BĂNG TÍNH NĂNG (Mốc 3).

## Việc tiếp theo
- Đứng ở thư mục gốc `CareSLA`, chạy lệnh `python -m http.server 8000`. Sau đó mở trình duyệt truy cập `http://localhost:8000/dashboard/` để xem giao diện (Fix Lỗi số 5).
- Mở URL `http://localhost:8000/dashboard/?plan=2` để demo tính năng thanh lý của hợp đồng thứ 2 (Fix lỗi số 6).
- Chạy test toàn bộ 6 kịch bản P1 giao ở cuối file review.
- Hoàn thiện vẽ sơ đồ kiến trúc và gộp báo cáo (Giai đoạn 4-5).
